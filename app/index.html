✨ Why This Stands Out

  • Query-adaptive planning — the agent parses intent/filters/entities and builds a fresh execution plan per query; it skips EDA and ML entirely when a query doesn't need them (see Preview Plan).
  • Forensic accounting — Benford's Law + threshold-proximity clustering catch structuring patterns deliberately mutated to evade flat-$9,999 rules.
  • Multi-agent committee — Transaction Monitoring, KYC/UBO, Sanctions/PEP, and Network Analyst agents vote independently; a Chair Agent synthesizes a real Risk Memo, not a single black-box score.
  • Runs on the real dataset — vectorized end-to-end (pandas groupby, sampled betweenness centrality) to stay responsive on the full 9.5M-row / 855k-account Kaggle SAML-D dataset, not just a toy sample.
  • Multimodal input — attach a transaction screenshot or KYC document; a vision model extracts details and folds them into the same committee pipeline.
